# Npcink Device Inventory 新用户快速开始

日期：2026-08-13

这份文档面向第一次安装 `Npcink Device Inventory` 的站点管理员，目标是在 10 到 15 分钟内完成插件启用、基础设置、设备录入和授权上传准备。

当前管理端和桌面客户端仅提供简体中文界面。

## 1. 安装插件

1. 登录 WordPress 后台。
2. 打开 `Plugins > Add New Plugin > Upload Plugin`。
3. 上传 `npcink-device-inventory.zip`。
4. 启用插件。
5. 打开 `Plugins > Device Inventory`。

启用后插件会创建自己的数据表和默认设置。除非管理员在卸载设置中明确启用删除数据，卸载时不会自动删除资产数据。

## 2. 先完成基础设置

打开后台的 `Settings` 标签页，建议先确认：

- 外部访问地址：通常留空；只有反向代理或对外域名与当前站点不一致时填写。
- 部门列表：根据公司部门增删。
- 客户端授权码：用于桌面上传软件。

建议每个用途单独创建一个客户端授权码，例如：

- `office-upload`
- `test-device-agent`

不用的授权码应及时禁用或删除。

## 3. 录入第一台电脑

1. 打开 `Computer Devices` 标签页。
2. 选择以下一种方式：
   - 在空状态中进入 `Data Tools`，下载标准 CSV 模板并导入已有电脑台账；
   - 安装桌面上传软件，导入后台生成的运行时配置后采集并上传本机信息。
3. 上传或导入完成后，回到 `Computer Devices` 检查列表和详情页。

`Computer Devices` 当前不提供手动新建入口；需要纯手工维护的非电脑设备，请在 `Custom Assets` 中新增。

## 4. 使用桌面上传软件

桌面上传软件是可选配套工具，不包含在 WordPress 插件 zip 中。请从项目 GitHub Releases 的最新版下载页获取：

https://github.com/npcink/npcink-device-inventory/releases/latest

当前提供 Windows x64 和 macOS Apple Silicon 构建。macOS 包尚未完成 Developer ID 签名与公证，Windows 包尚未完成代码签名，仅适合可信的内部试用环境；对外分发前应完成平台签名。下载后请核对 Release 中的 `SHA256SUMS`。

管理员需要先准备：

1. WordPress 站点地址。
2. 当前上传接口地址：

```text
https://example.com/wp-json/npcink-device-inventory/v1/device-observations
```

3. 后台生成的客户端授权码。

用户在桌面端导入后台生成的运行时配置，或填写上传地址、授权码和可选使用人后提交。使用人字段只填写人员姓名，不要填写工位、部门或设备用途。提交成功后，管理员可在后台 `Computer Devices` 中看到采集到的设备记录。同一台设备再次上传时，服务端会从硬件快照重新计算当前身份并更新原记录，避免重复建档。

## 5. 导入和导出

在 `Data Tools` 标签页中有两类用途不同的工具：

- 资产 CSV：用于日常表格交换、批量整理资产字段，不是完整备份。
- JSON 备份：用于同版本插件之间迁移或归档业务数据，包含资产、身份、采集快照和事件；不包含客户端令牌密钥和站点 URL。

灾备或迁移时必须使用 JSON 备份，并先执行导入预览。导入前建议备份数据库，不要把来自不可信来源的文件导入生产站点。

## 6. 日常维护建议

- 定期导出资产数据备份。
- 离职、设备报废或授权泄露时，及时禁用相关客户端授权码。
- 对设备上传地址使用 HTTPS。
- 只给可信管理员 `manage_options` 权限。
- 升级插件前先在测试站点验证核心流程。

## 7. 常见问题

### 插件会把设备数据发给第三方吗？

不会。插件正常运行时只把数据存储在当前 WordPress 站点数据库中。

客户端上传的原始硬件快照可能包含 IP、MAC、UUID、序列号和系统硬件信息。当前默认保留天数为 `0`，表示不自动清理；管理员应依据组织的数据保留政策手动处理或配置已实际启用的清理能力，不要把 `0` 理解为不保存。

### 没有桌面上传软件还能用吗？

可以。插件后台支持手动录入、自定义设备管理、导入导出和变更记录。

### 卸载会删除数据吗？

默认不会。只有管理员在卸载设置中启用删除数据后，卸载才会删除插件自有表和设置。

## 8. 首次上线检查清单

- 插件已启用。
- 后台页面可以正常打开。
- 至少生成一个客户端授权码。
- 未签名上传请求返回 `401`。
- 已记录管理员内部的数据采集和隐私告知口径。
