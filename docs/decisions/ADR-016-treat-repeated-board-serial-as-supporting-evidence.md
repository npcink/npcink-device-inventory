# ADR-016：重复主板序列号只作为辅助证据

## 状态

已接受

## 日期

2026-09-27

## 背景

生产数据中有多台 GreatWall H610M-A 同时报告主板序列号 `GW202407022024`。服务端把“厂商 + 型号 + 序列号”计算为全局唯一的 `baseboard_serial_v2`。如果第一台重新采集成功占用该身份，后续设备虽然有各自不同的系统 UUID，仍会因为主板序列号冲突返回 409。

另一个历史案例表明，即使系统 UUID、网卡和主机名相同，也不能仅凭身份信号自动合并两条管理员确认独立的资产；身份冲突可能来自克隆镜像、固件重复或历史采集错误。

## 决策

- `system_uuid_v2` 和 `pci_permanent_mac_v2` 的唯一拥有者优先于 `baseboard_serial_v2`。
- 如果更强身份唯一命中一台资产，而主板序列号属于另一台资产，上传继续写入命中的资产，并跳过这条冲突的主板辅助身份。
- 如果两个更强身份分别属于不同资产，仍然失败关闭并返回 `409 identity_evidence_conflict`。
- 归档资产与活跃资产出现冲突时，不自动合并；管理员确认独立设备后，只撤销会拦截上传的错误身份，并保留历史观察与审计事件。

## 后果

重复或批量烧录的主板序列号不会再阻塞有可靠系统 UUID/永久 PCI MAC 的采集。主板序列号仍可用于首次定位和辅助核对，但不能单独覆盖更强身份，也不能用编号、主机名或型号替代硬件证据。
