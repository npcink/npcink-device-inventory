# ADR-019：聚焦资产盘点、设备身份和采集上传

## 状态与日期

已接受，2026-11-10。用户授权按精简建议实施，并明确确认没有外部脚本调用手工添加身份接口，可以删除。

本决策替代 ADR-009、ADR-013 中的完整度评分、财务待补提醒、更新计划草案，以及 ADR-017 中继续保留手工添加身份 POST 接口的部分。其他身份、存储、上传和只读分析约束继续有效。

## 背景

项目的核心工作是维护资产台账、可靠识别设备、采集硬件事实并上传，供管理员查询、核对和处理变更。运行监控、系统维修工具入口、系统级故障材料与这个目标距离较远，却需要维护持续采样、平台命令、隐私边界和额外界面。

后台把任意缺项折算成百分比、把零金额视为资料缺失，以及用资产登记时间代替采购日期，会把未经证实的规则呈现为业务事实。更新计划草案目前只有选择、汇总和导出，不能形成实际采购流程。重复导出入口和依赖也增加了维护成本。

## 决策

1. 桌面端保留设置、排障、技术详情三个页面；删除运行监控、周期采样、历史曲线、macmon 调用及系统工具启动命令。
2. 深度排障包收缩为手动生成的本地上传排障包，保存脱敏硬件快照、身份检查、采集状态、配置摘要、应用日志尾部、说明和清单，格式标识为 `npcink-agent-support-v1`。不再收集系统事件、进程、驱动清单、转储或调试器输出。完整硬件反馈导出仍单独提供，并保留标识信息提示。
3. 后台保留资料缺项清单、字段筛选和对应 CSV；删除综合评分、按正金额计算的估值覆盖率和普遍要求补齐金额的提醒。责任人仅对在用设备要求；金额不参与资料完整性判断。
4. 采购日期只采用明确保存的采购事实，不回退到 `createdAt`；日期未知时不据此计算折旧和设备年龄。保留已保存金额、手工净值和估算规则，不回写历史数据。
5. 保留更新候选及依据、资产价值分析和普通分析导出；删除更新计划草案的勾选、部门汇总和单独导出。
6. 日常台账导出集中到资产列表；数据工具保留导入和完整 JSON 备份恢复。
7. `/assets/{uuid}/identities` 仅保留 GET；删除未被后台使用且无外部调用者的 POST 和处理方法。内部身份认领、冲突防护、上传和备份恢复中的身份数据继续保留。
8. 五个资产编号专用 BAT 合并为一个交互输入编号的入口，独立的 Windows 硬件身份核对工具继续保留。删除未使用的前端依赖。文档入口集中，历史材料保留原路径。

继续检查时补齐净值读取边界：明确手工零值、可计算零值和报废零值均为已知；默认存储零值且无法自动计算时为未知。详情标明未知，CSV / Excel 留空；汇总只纳入已知金额并说明未计入条数。零净值参与折旧，未报废设备可按零净值率成为更新候选；报废设备退出更新候选。存储和写入契约不变。

## 取舍与后果

保留全部旧功能会让项目继续承担监控和系统维修软件的成本；只隐藏界面仍需维护后台命令。因此删除相关实现和入口，使用上传排障所需的最小材料。

本轮不引入数据库迁移，不清理真实资产、观察记录、历史身份和备份格式。身份校验、HMAC、防重放、事务、软删除、硬件不确定性表达等核心约束继续有效。

客户端的 `runtime` CLI、运行监控 IPC、系统工具 IPC，以及身份 POST 不再属于支持接口。若以后确有业务需求，应先补充使用场景、证据和验收条件，再形成新决策。零金额是否代表未知仍由存储契约决定，不通过评分补造含义。

源码修改完成不代表已部署。Windows 原生采集及真实 WordPress 环境仍需在对应环境验收，发布继续遵守现有版本与打包流程。

实施和验证见[精简实施记录](../scope-simplification-2026-11-10.md)。

## 后续落实：移除无消费者的契约与重复配置

用户授权继续依次精简，并明确确认全局 `GET /observations` 无外部调用。删除该路由及专用全局搜索分页实现；保留 `/assets/{uuid}/observations`、分析接口、快照清理、上传和备份中的快照。移除没有业务消费者的 `countAvailableAssetsOnly` 活动设置契约，旧请求 / 备份中的该键忽略，不清整份 option，也不迁移或删除数据。

名称和采购价统一由资产主记录负责。停止新写 `metadata.purchase.title` / `total`，展示不再优先或回退读取这两份历史镜像；历史元数据保持原样，独立采购事实继续保留。完整列表不再持久化到 localStorage，保留内存查询缓存及后台首屏数据；启动精确清理旧列表缓存，不清保存筛选和布局。

新增弹窗仅保留实际可达的自定义资产录入，已有资产从详情编辑。导出保留范围、字段、常用方案和预览，固定 Excel 状态格配色，移除外观编辑器；变更列表删除不完整的隐藏姓名开关。以上是针对当前调用链及用户确认的范围收缩，不引入离线产品或完整脱敏产品。
