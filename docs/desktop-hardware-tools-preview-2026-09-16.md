状态：仅预览。用户要求先在本地确认外观并明确同意，才能正式发布。没有创建正式 tag、Release 或修改正式更新清单；3.2.3 / Agent 0.4.3 也仍未发布。

## 交付范围

- 普通采集共用显卡、显示器和电池查询。Windows 的 EDID 查询为空或缺少部分屏幕时，从按 PNP 实例匹配的 DesktopMonitor 查询补齐；不猜测序列号或复制多屏刷新率。
- macOS 普通采集读取显示和电源信息，复用现有规范化逻辑。
- 显卡与显示器同时显示，概览读取 Windows 当前分辨率字段。
- 无有效电池展示字段时隐藏入口；电量 0%、循环 0 仍有效；当前选中的电池变为空时回到处理器详情。
- 硬件反馈导出执行完整采集，不覆盖普通上传缓存。
- 身份自检只重新采集和展示状态，不上传。Windows 工具入口使用固定程序和参数；WinDbg 入口打开指定的微软 HTTPS 文档。
- 深度排障包增加 identity-check.json、hardware-probes.json、tools-guide.txt。身份摘要沿用脱敏前计算的状态。
